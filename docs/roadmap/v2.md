# Stir v2 — post-launch roadmap

Deferred from v1 launch per the no-new-features invariant. **Items here are NOT scoped, NOT prioritized, NOT promised.** This file exists so beta-tester asks, post-v1 spec backlog, and triggered-from-deferred-work refactors have a canonical destination — keeping the v1 launch scope honest.

When a beta tester asks for a feature, the agent's job is to:

1. Confirm it's not already in spec or in-flight (search `Specs/Stir-Full-Spec.md` and current Linear backlog).
2. Drop a one-line entry in §1 below with the date, anonymized tester ID, and the literal ask.
3. Move on. Do not file a Linear issue. Do not start scoping. Do not promise a timeline.

If a tester ask appears 3+ times across distinct testers, that's signal — surface to Daniel for a scope conversation.

This file is not authoritative; it's a holding pen. Anything here that converts to v1.x or v2 work gets a proper Linear issue under the Stir project at that point, with this file's entry referenced for provenance.

## §4. Margin / cost optimizations

Cost-model improvements that aren't load-bearing for v1 launch but worth a pass once unit economics are visible at scale:

- **Voice-path context pruning v2** — current refresh-bounded growth (ADR 0014) is correct but conservative. Once 60+ days of Live API observability lands, revisit prompt-token growth curves and consider tighter `refreshAtTurnCount` / `refreshAtPromptTokenCount` targets.
- **Implicit caching reactivation on Live API** — locked closed at v1 (ADR 0015) because Google's `BidiGenerateContent` doesn't fire implicit caching. If Google ships caching support for Live, the cap math in CLAUDE.md §Tier entitlements gets headroom — revisit voice caps and Pro annual margin.
- **Model-swap experiments** — Gemini 3 family; flash-lite for substitution; on-device Vision OCR vs Gemini scan-parse. Each is a separate spike; v2 because each one needs an eval pass and v1 has finite eval budget.
- **Pantry-scan single-image cost reduction** — scan-parse currently runs flash; flash-lite is half the rate. Eval coverage on confidence threshold + retry-on-low-confidence shape needed before swapping.
- **Audio-mode 200-token overhead** — undocumented Gemini Live overhead per turn (CLAUDE.md sharp-edge #15). If Google publishes a way to reduce or eliminate this, voice cost model loosens — revisit caps.
